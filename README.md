# comma-office — 쉼표(주)

취업 준비하다 지치면 잠깐 출근해서 쉬어 가는 가상 회사. 브라우저에서 도는 3D 웹이다.

**바로 해 보기: https://seoulbhin.github.io/comma-office/**

사원증을 찍고 들어가 내 자리, 탕비실, 옥상을 걸어 다닌다. 혼자 둘러보는 곳이라 서버가 없다.

| 공간 | 할 수 있는 것 |
|---|---|
| 로비 출근 게이트 | 리더기를 누르면 출근 도장. 안 찍으면 게이트 앞에서 멈춘다. 연속 출근일·최근 4주 기록 |
| 내 자리 | 모니터 켜고 끄기, 포스트잇에 할 일 적기(앞 4줄이 3D 포스트잇에 보인다) |
| 탕비실 | 커피 내리기(오늘 몇 잔째인지 센다), 간식 고르기, 냉장고에서 물 꺼내기 |
| 옥상 | 엘리베이터로 올라간다. 하늘이 내 PC 시각을 따라 낮·노을·밤으로 바뀌고 밤엔 별과 도시 불빛이 켜진다. 벤치에 앉기 |

조작: 바닥을 눌러 이동, 물건을 누르면 그 앞까지 걸어가서 동작, 드래그로 둘러보기, 휠(두 손가락)로 확대·축소.
기록(출근 도장·포스트잇·커피 잔 수)은 이 브라우저의 `localStorage` 에만 남는다.

## 실행

빌드 없음. 정적 파일 4개(`index.html`·`style.css`·`main.js`·`logic.js`)를 아무 웹 서버로 열면 된다.
Three.js 는 jsDelivr CDN 에서 버전을 고정해(`three@0.160.0`) 불러온다.

```bash
python -m http.server 8608
# http://localhost:8608
```

주소 뒤에 붙이는 옵션:

- `?hour=21` — 그 시각의 하늘로 본다(캡처·시험용)
- `?debug` — 콘솔에서 `window.comma` 로 아바타·카메라·동작 목록을 만질 수 있다

## 구조

```
index.html   화면 틀(HUD·안내 카드·패널)과 importmap
style.css    아이보리 바탕 + 주황 강조 하나
logic.js     3D 와 상관없는 규칙: 출근 도장·연속일, 시각별 하늘, 정문·게이트 경로
main.js      Three.js 장면. 건물·가구·사람을 전부 기본 도형(상자·원기둥·구)으로 코드에서 만든다
test_logic.mjs  logic.js 시험
```

외부 3D 모델·이미지·글꼴 파일은 하나도 없다. 간판·모니터·포스트잇 글자는 캔버스에 그려서 붙인다.

### 게이트 규칙

1층에는 지나가야 하는 선이 둘 있다. 정문(z=12)과 출근 게이트(z=7). 둘 다 가운데 통로로만 지나간다.
`planPath(from, to, stamped)` 가 갈 길을 점 목록으로 만들고, 도장 없이 안쪽으로 들어가려 하면
게이트 앞 점에서 끊고 `blocked: 'gate'` 를 돌려준다. 나가는 쪽은 도장 없이도 지나간다.

```bash
node test_logic.mjs   # 아무 출력 없이 끝나면 통과
```

## 일부러 단순하게 둔 것

- 가구와 부딪히지 않는다. 벽·게이트 통로만 경로로 지키고 책상은 통과한다
- 해의 높이는 6시 일출·18시 일몰로 고정한 사인 곡선이다(계절·위도 무시)
- 옥상은 건물 위가 아니라 멀리 떨어진 자리에 따로 만들고 엘리베이터에서 순간 이동한다. 1층 실내를 위에서 내려다볼 때 지붕이 가리지 않게 하려고
